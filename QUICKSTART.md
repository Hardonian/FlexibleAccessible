# Quickstart

## Prerequisites
- Node 20+
- Postgres and Redis for full-stack flows

## Setup
```bash
npm install
cp .env.example .env.local
npm run dev
```

## Validate before PR
```bash
npm run lint
npm run typecheck
npm run test
```
