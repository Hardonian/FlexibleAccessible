# Underrepresented Outreach Program - AROS

**Effective Date:** 2026-04-10  
**Status:** Active

---

## Purpose

Ensure AROS products serve all users, including those often underrepresented in technology: disability communities, aging populations, low-income users, and international audiences.

---

### Tier 1: Primary (This Quarter)

## Partnership Framework

### Partner Types

| Type | What We Offer | What They Offer |
|------|---------------|----------------|
| Advocacy orgs | Product feedback | User research access |
| Assistive tech | Integration | Co-marketing |
| Senior centers | Workshops | User research |
| Community orgs | Free tier | Distribution |

### Partnership Requirements

1. Aligned mission
2. Authentic representation
3. No exploitation
4. Reciprocal benefit

---

## Research Inclusion

### Requirements for All User Research

- [ ] Disability community included
- [ ] Multiple disability types represented
- [ ] Intersectional considerations
- [ ] Compensation offered
- [ ] Accessibility of research methods
- [ ] Results shared with participants

### Compensation Guidelines

| Activity | Compensation |
|-----------|--------------|
| Survey | $25 gift card |
| Interview | $50 gift card |
| Testing (1 hour) | $75 gift card |
| Advisory role | See advisory board |

## Communication Accessibility

### Multi-Format Content

| Format | Availability |
|--------|---------------|
| Text (plain) | ✅ All content |
| Audio description | Key content |
| Sign language video | Key content |
| Easy read | Major announcements |
| Multiple languages | See timeline |

### Accessibility Standards

All external communications:
- Plain language (reading level 8)
- Alt text on all images
- Captions on all video
- Screen reader tested
- Color contrast compliant
