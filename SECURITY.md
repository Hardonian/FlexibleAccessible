# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability, please report it responsibly.

### How to Report

1. **Email**: security@flexibleaccessible.com
2. **Subject**: `[SECURITY] Brief description`
3. **Include**:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

### Response Timeline

| Phase | Timeline |
|-------|----------|
| Acknowledgment | Within 24 hours |
| Initial Assessment | Within 72 hours |
| Patch Development | 1-2 weeks depending on severity |
| Disclosure | After patch released |

### Security Measures

- All code scanned for vulnerabilities before release
- Dependencies monitored via Dependabot
- Regular security audits
- Encrypted data at rest and in transit
- API keys never logged or exposed

### Scope

This security policy covers:
- FlexibleAccessible platform
- API endpoints
- Web application
- Browser extensions
- CI/CD integrations

### Out of Scope

- Third-party integrations (report to respective vendors)
- Client-side browser issues
- Social engineering attacks

## Acknowledgments

We thank security researchers who responsibly disclose vulnerabilities.
