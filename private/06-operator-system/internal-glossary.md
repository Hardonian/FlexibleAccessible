# Internal Glossary

**Status:** CURRENT STATE + RECOMMENDED  
**Purpose:** Keep commercial and technical language consistent.  
**Scope:** Product, billing, ops, finance terms.

- **Paid entitlement:** Server-side condition allowing access to private org workflows.
- **Private route:** Dashboard/org-scoped path not intended for anonymous/public usage.
- **Public scan:** Free top-of-funnel scan entry path.
- **First value:** First completed private scan that produces actionable findings.
- **Activation:** Customer reaches first value milestone.
- **Past due:** Subscription status requiring billing recovery actions and potential access lock.
- **Deferred revenue:** Cash received before full service delivery period is complete.
- **Reconciliation exception:** Any mismatch between Stripe/bank/internal ledger states.
- **Stop-ship condition:** Release blocker requiring fix before commercialization changes go live.
